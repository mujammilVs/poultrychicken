# Aamir Al Wagan Poultry Farm L.L.C (Baraka Al Ain) - Official Website

> **F R E S H   C H I C K E N · Q U A L I T Y · T R U S T**  
> *"Freshness You Trust. Quality You Deserve."*

A modern, responsive React.js website built with an advanced, clean, farm-fresh UI tailored exclusively for **Aamir Al Wagan Poultry Farm L.L.C** (trading as **Baraka Al Ain**), established in 2026 in Al Wagan, Al Ain, Abu Dhabi, UAE.

---

## 🌟 Key Highlights & Features

- **Exclusive Focus on Poultry & Farm Operations**:
  - 100% focused on Aamir Al Wagan Poultry Farm and Baraka Al Ain brand identity.
  - Zero unrelated filler or generic templates.
- **Dual Regulatory Certification & Standing**:
  - **ADDED**: Abu Dhabi Department of Economic Development Commercial Trade Licence.
  - **ADAFSA**: Abu Dhabi Agriculture and Food Safety Authority No Objection Certificate (NOC).
  - 100% Halal Certified in-house slaughterhouse.
- **Key Capacity Indicators**:
  - **25 Farm Locations** in Al Ain across 4 central hubs (Al Wagan, Abu Samrah, Al Arad, Al Jazeera).
  - **100 Poultry Sheds** with modern bio-secure climate management.
  - **2,000,000+ Birds** aggregate production capacity.
  - **10,000 Tonnes** annual in-house feed manufacturing capacity.
  - **4,000 Birds / Hour** in-house slaughterhouse speed.
- **Interactive B2B Pricing & Order Estimator**:
  - Allows supermarkets, HORECA, and wholesale buyers to configure bird weights (800g – 1400g+), volume, delivery destination across UAE emirates, and receive instant indicative estimates that auto-populate the inquiry form.
- **6-Stage Precision Operational Process**:
  - Interactive stepper: Planning ➔ Procurement ➔ Daily Management ➔ Health & Biosecurity ➔ Processing & Handling ➔ Dispatch.
- **Infrastructure Showcase**:
  - Feed mill, storage silos, RO water filtration, equipment rooms, in-house slaughterhouse, and refrigerated cold-chain fleet (0°C to 4°C).
- **Future Agricultural & Livestock Initiatives**:
  - Strategic roadmap covering Goat Farming, Fish Farming (Aquaculture), and Sustainable Agricultural Farming.
- **Leadership & Governance Structure**:
  - Managing Director, Farm Manager, Avian Veterinary Support, Accountant, Sales Executive.
- **Commercial Inquiry & Wholesale Form**:
  - Validation, customizable requirements, direct phone links, and 1-click WhatsApp integration.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Development Server
To run the website locally in development mode:
```bash
npm run dev
```
Open `http://localhost:3000` or the port shown in your terminal.

### Production Build
To create a production-ready optimized build:
```bash
npm run build
```
The output will be placed in the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```
